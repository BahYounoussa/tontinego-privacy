# Politique de Confidentialité — TontineGo

**Dernière mise à jour : Avril 2026**

---

## 1. Introduction

TontineGo est une application mobile de gestion de tontines développée par **Guinée Digital Pub (GDP)**, basée à Conakry, Guinée. Nous nous engageons à protéger la vie privée de nos utilisateurs.

---

## 2. Données collectées

Nous collectons les informations suivantes :

- Nom complet
- Numéro de téléphone
- Données de tontines (noms, montants, paiements)
- Données d'utilisation de l'application

---

## 3. Utilisation des données

Vos données sont utilisées uniquement pour :

- Gérer vos tontines et paiements
- Vous permettre de récupérer votre compte
- Améliorer l'expérience de l'application

**Vos données ne sont jamais vendues à des tiers.**

---

## 4. Stockage et sécurité

Vos données sont stockées de manière sécurisée sur **Firebase (Google Cloud)**, protégées par chiffrement. L'accès est sécurisé par votre code PIN à 4 chiffres.

---

## 5. Partage des données

Nous ne partageons pas vos données personnelles avec des tiers, sauf obligation légale. Les données partagées via WhatsApp le sont uniquement à votre initiative.

---

## 6. Vos droits

Vous avez le droit de :

- Accéder à vos données
- Modifier vos informations
- Supprimer votre compte et vos données
- Contacter notre support pour toute question
